# مراقب أسعار مصر

حل مجاني يجمع GitHub Actions مع متابعة محلية عبر Chrome. لا يراقب كل المواقع أو التطبيقات ولا يضمن التقاط كل Flash Sale.

[حالة السحابي](data/STATUS.md) · [سجل التشغيل](https://github.com/eldeebvs-code/black-friday-intelligence/actions)

رأس Amazon بديل أقل قدرة 25W، وليس إثبات أصالة أو اعتماد للهاتف Galaxy S26 FE. قدرة 45W وحدها لا تثبت PPS أو التوافق. افحص البائع والفاتورة والضمان قبل الشراء. لا شراء تلقائي.

## التوقيت والتحقق

- السحابي يطلب التشغيل في الدقائق 7 و22 و37 و52 من الساعة. قد يؤخر GitHub التشغيل أو يفوت جولة؛ يعمل والكمبيوتر مغلق.
- المحلي ينتظر 15 دقيقة بعد كل دورة؛ يحتاج الكمبيوتر مستيقظًا والإنترنت وChrome.
- أول قراءة خط أساس. تنبيه عند انخفاض 15% عن أقل سعر متوفر مرصود خلال 30 يومًا لنفس البائع والمنتج والاختيار، بعد قراءة ثانية.
- تنبيه عودة التوفر منفصل للأهداف المحددة. محول Jumia التجريبي يميز الخصم المعلن عن الانخفاض التاريخي؛ غير مفعل حاليًا.
- لا رسالة عروض كل دورة. تقرير حالة مرة كل 24 ساعة في أول دورة متاحة، وعند تعطل مصدر أو تعافيه.
- منع تكرار نفس الاختيار والسعر 90 يومًا؛ حد 5 عروض للدورة السحابية و3 للمحلية. إذا وصل التنبيه ثم فشل حفظ الحالة قد يتكرر؛ لا ضمان exactly-once.
- الأسعار قبل الشحن وكوبونات السلة/الحساب. التاريخ يبدأ من أول رصد. لا ادعاء بأنه الأرخص في مصر.
- منتجات Vodafone الدوارة قد تتأخر إعادة زيارتها لساعات؛ ثبّت المنتجات المهمة.

## التأكد من التشغيل

افتح تقرير الحالة: الوقت حديث والمصادر المفعلة ok. error أو partial تعني عطلًا يحتاج مراجعة. راجع نجاح خطوة حفظ التاريخ في Actions. توقف Actions بالكامل يمنع رسائل الحالة نفسها.
الحالة السحابية في data/state.json والتقرير في data/status.json. توجد نسخة استعادة Actions لمدة 14 يومًا. لا تحذف التاريخ عند التحديث.

## GitHub وTelegram

1. فعّل Actions إن طلب GitHub ذلك. الجدول يعمل من main.
2. يحتاج التشغيل صلاحية كتابة data/ المحددة في workflow؛ راجع Settings → Actions → General إن منعتها سياسة المستودع. قواعد الفرع قد تمنع الحفظ.
3. أنشئ البوت عبر BotFather وافتحه واضغط Start. لا تنشر التوكن.
4. في Settings → Secrets and variables → Actions أضف TELEGRAM_BOT_TOKEN وTELEGRAM_CHAT_ID. يمكن معرفة معرف المحادثة محليًا بتشغيل python tools/telegram_chat_id.py بإدخال مخفي.
5. Actions → Egypt Price Watcher → Run workflow واختَر test_telegram لاختبار الاتصال. وصول الرسالة هو التأكيد.

أسرار GitHub لا يمكن استرجاعها للجهاز. لا تضعها في الملفات أو Issues أو المحادثات. غيابها يسمح بجمع التاريخ دون إرسال؛ فشل الإرسال لا يُسجل كنجاح.
لم نضف خدمة مدفوعة. راجع [حدود الجدولة](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)؛ الجداول العامة قد تُعطّل بعد 60 يومًا من عدم نشاط المستودع، والتوقيت غير مضمون.

## المحلي على Windows

ثبّت Python وChrome ثم شغّل:

```sh
python -m pip install playwright
python local_secrets.py
python local_watch.py --notify
```

نافذة local_secrets.py تختبر Telegram ثم تحفظ البيانات بتشفير Windows لحساب المستخدم في local-secrets.bin المستبعد من Git. لا تستخدم جلسة المتصفح الشخصية ولا تتجاوز الحجب أو CAPTCHA.
python local_watch.py --once يفحص مرة دون إرسال. التاريخ والتقرير في local-data/. يمنع البرنامج تشغيل نسختين متزامنتين. بعد إعادة تشغيل الكمبيوتر شغّل المحلي مجددًا؛ لم نثبت بدءًا تلقائيًا ولم نغير إعدادات الطاقة.

## إضافة وحذف المنتجات

- config.json للسحابي وlocal-config.json للمحلي. enabled: false يوقف المصدر.
- الغزاوي وRaya: targets مع تطابق الموديل والرابط وSKU إن وجد.
- Vodafone: pinned_paths لمسارات /en/prod/...، وbatch_size لعدد الصفحات الدوارة.
- Amazon المحلي: targets يحتوي asin وurl وmodel وdescription. صفحة المنتج يجب أن تطابق الموديل وتعرض سعرًا وبائعًا واضحين؛ حذف الكائن يوقفه.
- exclude_keys يستبعد اختيارًا بمفتاحه من سجل الحالة. drop_percent حد الانخفاض، وdaily_health للتقرير اليومي.
- إضافة اسم متجر لا تضيف دعمه. غير المفعّل يحتاج اختبارًا حيًا ناجحًا قبل التفعيل.

## البحث الشخصي في Telegram

افتح البوت من زر «ابحث عن منتج» في قناة @NOV_OFFERS واضغط Start، ثم أرسل اسم المنتج والموديل مثل «سامسونج 45W» أو /search Samsung 45W. /sources يعرض النطاق و/privacy يوضح الخصوصية.

هذه نسخة بحث في سجل الأسعار، وليست بحثًا مباشرًا شاملًا: تعرض حتى 5 مطابقات متوفرة رُصدت خلال 24 ساعة، مرتبة بالسعر مع اختلاف المواصفات والبائع ووقت الرصد. لا تعني أن المنتجات متكافئة أو أصلية. روابط المستخدم تُطابق السجل فقط ولا تُفتح. لا متابعة شخصية مستمرة بعد الطلب بعد.

تعمل ضمن دورة Actions كل 15 دقيقة تقريبًا وقد تتأخر. تستقبل حتى 20 تحديثًا في الدورة وبحد أقصى 3 ردود للمستخدم في الدفعة؛ الطلبات الزائدة في الدفعة لا تُجاب. ليست مناسبة لحمل جماهيري كبير دون توسعة. /start و/help يشرحان الحدود. لا تشغيل متزامن لمستقبل getUpdates آخر ولا webhook؛ وجود webhook يُوقف المستقبل دون حذفه.

لا تحفظ نصوص الطلبات أو معرفات المستخدمين في GitHub أو السجلات. data/search-cursor.json يحتوي مؤشر تحديث رقمي واسم البوت العام فقط، وdata/search-status.json حالة التشغيل والعدد الإجمالي. تليجرام يحتفظ بالرسائل وفق سياسته. فشل الرد لا يؤكد استلام الطلب، لكن انهيار التشغيل بعد الإرسال وقبل حفظ المؤشر قد يكرر الرد. بعد حظر المستخدم البوت يتم تجاوز الطلب.
